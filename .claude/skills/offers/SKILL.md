## Process
1. Score the current offer with the value equation: (Dream outcome × Likelihood of achieving it) ÷ (Time delay × Effort). Find the weakest factor.
2. Generate offer upgrades for that factor: bonuses that remove next obstacles, guarantees (money-back, results, "we'll do it for you"), faster start (templates, done-for-you onboarding), bundles, tiers, trials/samples, financing.
3. Name the offer (specific, outcome-led). Add real scarcity/urgency only (cohorts, seasonal stock, launch pricing with an end date).

## Output
- Current offer diagnosis
- 3 alternative offers, each: name · what's included · price framing · guarantee · urgency · who it's for
- Recommended offer + one-paragraph pitch + test plan
