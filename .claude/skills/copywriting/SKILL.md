## Process
1. Confirm: page/asset, audience segment, awareness level (unaware → most aware), single goal/CTA.
2. Pick a framework: PAS (problem-agitate-solve), AIDA, Before-After-Bridge, or the landing-page stack below.
3. Use customer words from the message bank; specific > clever; benefits before features; one idea per section.

## Landing page stack
Hero (headline = outcome, subhead = how/for whom, CTA, proof snippet) → social proof bar → problem → solution/how it works (3 steps) → benefits (3) → proof (testimonials, numbers, logos) → objection handling/FAQ → offer + guarantee → final CTA.

## Output
Full copy with section labels, 3 headline options with rationale, CTA variants, and meta title/description for web pages. Match the brand voice guide.
