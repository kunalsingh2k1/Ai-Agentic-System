# co-marketing · Demand Generation

## Setup
1. Brand: use the slug in the arguments (`$ARGUMENTS`); else the slug in `brands/.active`; else ask which brand in `brands/`.
2. Read `brands/<slug>/brand.md`. If it is missing, stop and suggest `/hub-onboard`.
3. Read earlier outputs this skill builds on (latest file of each, if present):
- `01-intel/customer-research`
- `01-intel/prospecting`

## Process
1. Find partners: same audience, non-competing, similar size or bigger (list 15 with reasons).
2. Pick formats: co-hosted webinar/live, joint lead magnet/report, newsletter swap, bundle/discount, giveaway, integration launch, guest content, event booth sharing.
3. Define value exchange so both sides win (leads shared, audience size, effort split).
4. Outreach: short personalized pitch with a specific idea and what they get.

## Output
Partner shortlist with fit score, 3 campaign concepts, outreach email drafts, joint campaign plan (timeline, responsibilities, assets, tracking with UTMs/codes, success metrics).
